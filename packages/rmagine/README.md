# rmagine (trimmed)

This repository carries only the upstream rmagine CPU core and Embree backend
needed by the MID-360 simulator. CUDA, OptiX, Vulkan, Ouster, applications,
examples, tests, documentation generation and binary-package generation are
not included.

Upstream: <https://github.com/uos/rmagine>
